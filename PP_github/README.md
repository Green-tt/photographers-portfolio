# 📸 Photographer Portfolio — дипломный проект

Веб-приложение «Портфолио фотографа», созданное на **FastAPI** с использованием **Jinja2-шаблонов**, включает галерею, систему регистрации/авторизации и личный кабинет пользователя.

---

## 🎯 Цели проекта

Проект создан для того, чтобы фотограф мог:

- публиковать свои работы в удобной галерее,
- демонстрировать портфолио клиентам,
- получать заявки,
- вести личный кабинет.

Пользователи сайта:

- **Гости** — могут просматривать галерею.
- **Фотограф / автор** — может входить в свой аккаунт.
- **Зарегистрированные пользователи** — могут авторизоваться.

---

## ⚙️ Функционал приложения

### 👤 Пользователи
- Регистрация нового пользователя  
- Авторизация  
- Простая сессия (в оперативной памяти)

### 🖼️ Галерея
- Просмотр фотографий  
- Адаптивное отображение изображений  
- Модальное окно увеличенного просмотра

### 🏠 Главная страница
- Информация о фотографе  
- Биография  
- Пример работ

---

## 🛠 Используемый стек технологий

### Backend:
- **FastAPI**
- **Python 3**
- **SQLite (через встроенный sqlite3)**

### Frontend:
- **HTML + Jinja2**
- **CSS (адаптивная верстка)**
- **Vanilla JS**

### Инфраструктура:
- **Uvicorn** — ASGI-сервер  
- **Файловая структура**:  
  - `/static` — стили, скрипты, изображения  
  - `/templates` — Jinja2 HTML  
  - `main.py` — основной сервер  
  - `database.py` — работа с SQLite
